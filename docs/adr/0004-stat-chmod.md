# ADR-0004: Статы содержимого и chmod

Статус: принято. Дата: 2026-10-02.

1. fs_stat возвращает размер в байтах и отдельный content_type, не смешивая его
   с типом объекта Entry.type. Строки считаются точно по CR/LF/CRLF на всём тексте.
2. Консервативное auto: BOM/UTF-8, без эвристики старых кодировок. Binary по
   сигнатурам/controls; undecodable/size_limit/file_changed — unknown, строки null.
   Для старой кодировки доступен явный encoding. Не заявляем универсальный детектор.
3. include_stats обогащает только возвращаемую страницу, не влияет на total и
   фильтрацию. Ошибка обогащения при on_error=skip сохраняет Entry со stats=null.
4. Для совместимости Entry.size сохранён, новое stats nullable. Поисковые схемы
   версионируются отдельно от новых Stat/Chmod контрактов.
5. fs_chmod принимает полную восьмеричную маску и dry_run, работает только на POSIX,
   не рекурсивен, возвращает реальные права после вызова. Корень области защищён.
6. Общая workspace-политика, журнал, standalone-генерация и прежние тесты сохранены.
