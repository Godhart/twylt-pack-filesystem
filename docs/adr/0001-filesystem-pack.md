# ADR-0001: самостоятельный filesystem pack

Статус: принято. Версия: 0.1.0. Дата: 2026-10-02.

1. Один инструмент на операцию, префикс `fs_`; TWYLT 1.0.0, Pydantic 2, Python 3.11+. Схемы инструментов версионируются отдельно (1.0.0).
2. Общая исходная реализация в `src/common.py` встраивается генератором в каждый `tool.py`: ToolPack Builder может переносить файлы без локальных импортов. Все инструменты имеют одинаковый набор requirements для простой воспроизводимой установки.
3. list/find/glob используют один обход и фильтры; различаются глубиной по умолчанию и поисковым предикатом. Фильтры не отсекают поддеревья. Корень не включён, глубина детей 1.
4. Offset/limit выбраны для простоты агента. Каждый вызов считает полный total; нет снимка дерева и устойчивых курсоров при параллельных изменениях. В ответе сохраняется признак неполного обхода и ошибки.
5. Симлинки в поиске не обходятся. Файлы можно читать через ссылки, delete удаляет саму ссылку, copy/move сохраняют ссылку. Работа идёт с правами процесса, не в виртуальной песочнице.
6. Регекс применяется к имени, дополнительно к относительному пути; glob сегментный, регистрозависимый и одинаковый на ОС. POSIX owner/mode явно не поддержаны на Windows, вместо молчаливой имитации. Эффективная доступность вынесена в отдельный фильтр access.
7. Текст читается целиком в пределах max_bytes, затем режется по строкам с нулевым offset. UTF BOM/UTF-8 имеют приоритет, прочие кодировки определяются эвристически. Это ограничивает память файла и делает total_lines однозначным, но не подходит для огромных логов.
8. Структуры должны быть переносимы через JSON: даты становятся ISO-строками, дубли ключей и нестроковые ключи отклоняются. PyYAML SafeLoader; TOML из стандартной библиотеки, запись через tomli-w. Комментарии не сохраняются.
9. Markdown отдаёт вложенный token AST markdown-it-py с исходными диапазонами, без семантического анализа, исполнения HTML и рендеринга. Включены table/strikethrough.
10. Запись/копирование обычных файлов публикуются из временного файла в том же каталоге. Для no-clobber используется hard link, для overwrite — os.replace. Новые текстовые файлы сохраняют ограниченные права mkstemp, существующие mode-биты копируются при замене.
11. Назначение copy/move всегда точное. Деревья не сливаются, recursive delete явный. Move между томами и операции над деревьями не транзакционны; автоматического отката нет. Параллельные writers требуют внешней синхронизации.
12. Накопительные тесты включают публичный TWYLT describe, CLI argument/stdin/file режимы, автономный перенос tool.py и бизнес-сценарии файловой системы. Реальный прогон текущей сборки: Linux/Python 3.12; другие ОС не заявляются проверенными.
