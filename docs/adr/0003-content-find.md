# ADR-0003: Полнотекстовый фильтр find

Статус: принято. Дата: 2026-10-02.

1. Необязательный вложенный content-контракт только для find. Общие рекурсивные
   параметры вынесены в RecursiveInput, чтобы glob не получал эту опцию неявно.
2. По умолчанию буквальный текст, regex включается явно. Проверка по всему тексту,
   Unicode case-insensitive по флагу. Валидация regex/codec до обхода.
3. Переиспользовать декодирование и контроль путей read, ограничить байты на файл.
   Ничего не читать для файлов, не прошедших метаданные; ссылки исключать.
4. Сохранить SearchResult без snippets: один найденный файл — один entry;
   total и пагинация считают файлы. Для содержимого доступен read.
5. NUL-бинарные кандидаты по умолчанию исключаются, остальные ошибки используют
   on_error. Пропущенные ошибки делают complete=false. Отказы workspace нельзя
   подавить или превратить в успешный частичный ответ; сохраняется JSONL-аудит.
6. Политика workspace 1.0.0 неизменна. Нет полнотекстового индекса, новых зависимостей
   или таймаута re на файл; общий таймаут остаётся в runner.
