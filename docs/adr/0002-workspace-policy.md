# ADR: Виртуальный корень и журнал инцидентов

Статус: принято. Дата: 2026-10-02.

1. Корень доверенного runner обязателен, без режима неограниченного fallback.
   Агент не может менять его входным JSON. Describe не требует рабочей области.
2. Все внешние пути POSIX-виртуальные; исключение — относительные к repo Git paths.
   Физические пути больше не являются прежним интерфейсом; версия input schema 2.
3. Один идентичный src/workspace.py в обоих паках встраивается генератором:
   самостоятельность tool.py для ToolHub сохраняется, новая pip-зависимость не нужна.
4. Запрет symlink/junction, hardlink и внешнего st_dev. Поиск может возвращать
   lstat-метаданные ссылки без её раскрытия. Изменения дерева требуют preflight.
5. JSONL журнал содержит только отказы политики. По умолчанию stderr, опционально
   внешний файл 0600/append/fsync. Невозможность вести заданный журнал — отказ,
   резервное событие stderr. Контент файлов и remote URL не записываются.
6. Необязательные transport-path проверки TWYLT недостаточны: mixin проверяет
   cwd/input/output до автоматического unlink output и повторно перед записью.
   Сохраняются штатные ошибки TWYLT и их коды.
7. Git имеет неявные пути, поэтому проверяются .git/config и remotes/хранилища,
   отключены hooks/global config и выполнение пользовательских filters.
8. Проверки не закрывают TOCTOU и не заменяют изоляцию процесса. Эти границы явно
   описаны, контейнер/ОС sandbox остаётся задачей runner.
