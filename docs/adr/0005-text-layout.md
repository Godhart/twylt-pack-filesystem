# ADR-0005: Форматирование текстового файла

Статус: принято. Дата: 2026-10-02.

1. Переиспользовать полностью декодированный текст fs_stat для определения
   line_ending и indentation без дополнительного чтения файлов.
2. Encoding уже входил в FileStats; добавить provenance encoding_source,
   сохранив консервативное автоопределение BOM/UTF-8. Не объявлять догадку доказанной.
3. CRLF — единый разделитель. Смешение CRLF/LF/CR — mixed, отсутствие — none.
4. Отступы — ведущие ASCII space/tab только у непустых строк, mixed как внутри
   одной строки, так и между строками. Не оценивать ширину отступа.
5. Null для non-text/unknown, none для текста без данного признака. Общий FileStats
   обеспечивает одинаковый ответ отдельной команды и обогащённых списков.
6. Входы не меняются; выходы stat и поиска получают minor schema bump.
